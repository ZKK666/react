# 07 - 性能优化最佳实践

## React 性能优化的核心思想

React 性能优化的核心是：**减少不必要的渲染和计算**。

优化策略分为三个层次：
1. **避免重新渲染**：组件级别的优化
2. **优化渲染过程**：减少 Render 阶段的计算量
3. **优化用户体验**：代码分割、懒加载、并发特性

## 组件级别的优化

### 1. React.memo - 避免函数组件重渲染

```javascript
// ❌ 问题：父组件更新导致子组件无意义的重渲染
function Parent() {
  const [count, setCount] = useState(0);
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>Count: {count}</button>
      <Child data="static" />  {/* 每次 count 变化都重渲染 */}
    </div>
  );
}

function Child({ data }) {
  console.log('Child render');
  return <div>{data}</div>;
}

// ✅ 使用 React.memo
const Child = React.memo(function Child({ data }) {
  console.log('Child render');  // 只在 data 变化时打印
  return <div>{data}</div>;
});

// ✅ 自定义比较函数
const Child = React.memo(
  function Child({ user }) {
    return <div>{user.name}</div>;
  },
  (prevProps, nextProps) => {
    // 返回 true 表示不重渲染
    return prevProps.user.id === nextProps.user.id;
  }
);
```

### 2. PureComponent - 类组件优化

```javascript
// ❌ 普通类组件
class Child extends React.Component {
  render() {
    console.log('Child render');
    return <div>{this.props.data}</div>;
  }
}

// ✅ PureComponent：浅比较 props 和 state
class Child extends React.PureComponent {
  render() {
    console.log('Child render');  // 只在 props/state 变化时打印
    return <div>{this.props.data}</div>;
  }
}

// ✅ 手动控制：shouldComponentUpdate
class Child extends React.Component {
  shouldComponentUpdate(nextProps, nextState) {
    // 自定义比较逻辑
    return this.props.data !== nextProps.data;
  }

  render() {
    return <div>{this.props.data}</div>;
  }
}
```

### 3. useCallback - 缓存函数

```javascript
function Parent() {
  const [count, setCount] = useState(0);
  const [items, setItems] = useState([]);

  // ❌ 每次渲染都创建新函数 → Child 总是重渲染
  const handleClick = () => {
    console.log('clicked');
  };

  // ✅ 使用 useCallback 缓存函数
  const handleClick = useCallback(() => {
    console.log('clicked');
  }, []);  // 依赖为空，函数永不变

  // ✅ 函数依赖外部变量
  const handleAddItem = useCallback((item) => {
    setItems(prev => [...prev, item]);  // 使用函数式更新，不依赖 items
  }, []);  // 仍然不需要依赖 items

  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>Count: {count}</button>
      <Child onClick={handleClick} />  {/* count 变化时不重渲染 */}
    </div>
  );
}

const Child = React.memo(({ onClick }) => {
  console.log('Child render');
  return <button onClick={onClick}>Click me</button>;
});
```

### 4. useMemo - 缓存计算结果

```javascript
function ExpensiveComponent({ items, filter }) {
  // ❌ 每次渲染都重新计算
  const filteredItems = items.filter(item => item.type === filter);

  // ✅ 使用 useMemo 缓存计算结果
  const filteredItems = useMemo(() => {
    console.log('filtering...');
    return items.filter(item => item.type === filter);
  }, [items, filter]);  // 只在 items 或 filter 变化时重新计算

  return (
    <ul>
      {filteredItems.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  );
}
```

## 列表渲染优化

### 1. 使用正确的 key

```javascript
// ❌ 错误：使用 index
{items.map((item, index) => (
  <Item key={index} data={item} />  // 删除/插入时性能差
))}

// ✅ 正确：使用稳定的 ID
{items.map(item => (
  <Item key={item.id} data={item} />
))}
```

### 2. 虚拟列表（Virtual List）

长列表只渲染可见区域：

```javascript
import { FixedSizeList } from 'react-window';

function LargeList({ items }) {
  // ❌ 渲染所有 10000 个元素
  return (
    <div>
      {items.map(item => (
        <div key={item.id} style={{ height: 50 }}>
          {item.name}
        </div>
      ))}
    </div>
  );

  // ✅ 使用虚拟列表，只渲染可见的元素
  return (
    <FixedSizeList
      height={600}      // 容器高度
      itemCount={10000} // 总数
      itemSize={50}     // 每项高度
      width="100%"
    >
      {({ index, style }) => (
        <div style={style}>
          {items[index].name}
        </div>
      )}
    </FixedSizeList>
  );
}
```

### 3. 分页和无限滚动

```javascript
// 分页
function PaginatedList({ items, pageSize = 20 }) {
  const [page, setPage] = useState(0);

  const displayedItems = useMemo(() => {
    const start = page * pageSize;
    return items.slice(start, start + pageSize);
  }, [items, page, pageSize]);

  return (
    <div>
      <ul>
        {displayedItems.map(item => (
          <li key={item.id}>{item.name}</li>
        ))}
      </ul>
      <button onClick={() => setPage(p => p - 1)} disabled={page === 0}>
        Previous
      </button>
      <button onClick={() => setPage(p => p + 1)}>Next</button>
    </div>
  );
}

// 无限滚动
function InfiniteList() {
  const [items, setItems] = useState([]);
  const [page, setPage] = useState(0);
  const [hasMore, setHasMore] = useState(true);

  const loadMore = useCallback(async () => {
    const newItems = await fetchItems(page);
    if (newItems.length === 0) {
      setHasMore(false);
    } else {
      setItems(prev => [...prev, ...newItems]);
      setPage(p => p + 1);
    }
  }, [page]);

  useEffect(() => {
    loadMore();
  }, []);

  return (
    <InfiniteScroll
      dataLength={items.length}
      next={loadMore}
      hasMore={hasMore}
      loader={<div>Loading...</div>}
    >
      {items.map(item => (
        <div key={item.id}>{item.name}</div>
      ))}
    </InfiniteScroll>
  );
}
```

## 代码分割和懒加载

### 1. React.lazy - 组件懒加载

```javascript
// ❌ 同步导入：所有代码都在初始 bundle 中
import HeavyComponent from './HeavyComponent';

function App() {
  return (
    <div>
      <HeavyComponent />
    </div>
  );
}

// ✅ 异步导入：按需加载
const HeavyComponent = React.lazy(() => import('./HeavyComponent'));

function App() {
  return (
    <div>
      <Suspense fallback={<div>Loading...</div>}>
        <HeavyComponent />
      </Suspense>
    </div>
  );
}
```

### 2. 路由懒加载

```javascript
import { lazy, Suspense } from 'react';
import { BrowserRouter, Routes, Route } from 'react-router-dom';

// 懒加载路由组件
const Home = lazy(() => import('./pages/Home'));
const About = lazy(() => import('./pages/About'));
const Dashboard = lazy(() => import('./pages/Dashboard'));

function App() {
  return (
    <BrowserRouter>
      <Suspense fallback={<div>Loading page...</div>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
          <Route path="/dashboard" element={<Dashboard />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}
```

### 3. 预加载优化

```javascript
// 鼠标悬停时预加载
function NavLink({ to, children }) {
  const handleMouseEnter = () => {
    // 预加载组件
    import(`./pages/${to}`);
  };

  return (
    <Link to={to} onMouseEnter={handleMouseEnter}>
      {children}
    </Link>
  );
}
```

## 状态管理优化

### 1. 状态下沉

```javascript
// ❌ 状态提升过高
function App() {
  const [inputValue, setInputValue] = useState('');  // 影响整个 App

  return (
    <div>
      <Header />
      <SearchBox value={inputValue} onChange={setInputValue} />
      <HeavyComponent />  {/* inputValue 变化时也重渲染 */}
    </div>
  );
}

// ✅ 状态下沉到需要的组件
function App() {
  return (
    <div>
      <Header />
      <SearchBox />  {/* 状态封装在内部 */}
      <HeavyComponent />  {/* 不受影响 */}
    </div>
  );
}

function SearchBox() {
  const [inputValue, setInputValue] = useState('');  // 局部状态

  return (
    <input
      value={inputValue}
      onChange={(e) => setInputValue(e.target.value)}
    />
  );
}
```

### 2. 拆分状态

```javascript
// ❌ 单个大对象
const [formData, setFormData] = useState({
  name: '',
  email: '',
  address: '',
  phone: '',
  // ... 20 个字段
});

// 任何一个字段变化都会触发所有依赖 formData 的组件重渲染

// ✅ 拆分成独立状态
const [name, setName] = useState('');
const [email, setEmail] = useState('');
const [address, setAddress] = useState('');
// ...

// 或使用 useReducer
const [state, dispatch] = useReducer(formReducer, initialState);
```

### 3. 使用 useReducer 管理复杂状态

```javascript
// 复杂的状态更新逻辑
function TodoList() {
  const [state, dispatch] = useReducer(todoReducer, {
    todos: [],
    filter: 'all',
    loading: false,
  });

  const addTodo = useCallback((text) => {
    dispatch({ type: 'ADD_TODO', payload: text });
  }, []);

  const toggleTodo = useCallback((id) => {
    dispatch({ type: 'TOGGLE_TODO', payload: id });
  }, []);

  // dispatch 引用稳定，不需要作为依赖
  return (
    <div>
      <AddTodoForm onAdd={addTodo} />
      <TodoItems todos={state.todos} onToggle={toggleTodo} />
    </div>
  );
}
```

## 图片和资源优化

### 1. 图片懒加载

```javascript
function LazyImage({ src, alt }) {
  const [imageSrc, setImageSrc] = useState(null);
  const imgRef = useRef();

  useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setImageSrc(src);
          observer.unobserve(imgRef.current);
        }
      },
      { threshold: 0.1 }
    );

    if (imgRef.current) {
      observer.observe(imgRef.current);
    }

    return () => observer.disconnect();
  }, [src]);

  return (
    <img
      ref={imgRef}
      src={imageSrc || 'placeholder.jpg'}
      alt={alt}
    />
  );
}
```

## 高频面试题

### Q1: React 性能优化有哪些手段？

**答案**：

**组件级别**：
1. **React.memo**：避免函数组件不必要的重渲染
2. **PureComponent**：类组件的浅比较优化
3. **shouldComponentUpdate**：自定义更新逻辑

**Hooks 级别**：
4. **useCallback**：缓存函数，避免子组件重渲染
5. **useMemo**：缓存计算结果，避免重复计算
6. **useReducer**：管理复杂状态，dispatch 引用稳定

**列表优化**：
7. **正确的 key**：使用稳定的 ID，而非 index
8. **虚拟列表**：长列表只渲染可见区域
9. **分页/无限滚动**：分批加载数据

**代码分割**：
10. **React.lazy + Suspense**：按需加载组件
11. **路由懒加载**：分割路由页面
12. **动态 import**：按需加载模块

**状态管理**：
13. **状态下沉**：状态放在最近的公共父组件
14. **状态拆分**：避免单个大状态对象
15. **Context 优化**：拆分 Context，使用 memo

**其他**：
16. **图片懒加载**：可视区域外的图片延迟加载
17. **防抖/节流**：减少高频事件处理
18. **Web Worker**：将计算密集任务移到后台线程

### Q2: 什么时候使用 React.memo？

**答案**：

**适合使用 React.memo 的场景**：

1. **纯展示组件**：
```javascript
// 只依赖 props，没有副作用
const UserCard = React.memo(({ user }) => (
  <div>
    <h3>{user.name}</h3>
    <p>{user.email}</p>
  </div>
));
```

2. **props 不经常变化**：
```javascript
// header 内容很少变化
const Header = React.memo(({ title, logo }) => (
  <header>
    <img src={logo} alt="Logo" />
    <h1>{title}</h1>
  </header>
));
```

3. **渲染成本高**：
```javascript
// 包含复杂计算或大量子组件
const DataVisualization = React.memo(({ data }) => {
  // 复杂的图表渲染
  return <Chart data={data} />;
});
```

**不适合使用 React.memo 的场景**：

1. **props 频繁变化**：
```javascript
// ❌ 每次渲染 props 都不同，memo 没意义
const Counter = React.memo(({ count }) => <div>{count}</div>);
```

2. **组件很简单**：
```javascript
// ❌ 渲染成本低，比较成本可能更高
const SimpleDiv = React.memo(({ text }) => <div>{text}</div>);
```

3. **props 是对象/数组/函数，且每次都是新引用**：
```javascript
// ❌ 每次 parent 渲染都创建新对象，memo 失效
<Child data={{ name: 'Alice' }} />  // 每次都是新对象

// ✅ 使用 useMemo 稳定引用
const data = useMemo(() => ({ name: 'Alice' }), []);
<Child data={data} />
```

### Q3: useCallback 和 useMemo 的使用场景？

**答案**：

**useCallback 使用场景**：

```javascript
// 1. 作为子组件的 props（子组件使用了 React.memo）
const Parent = () => {
  const handleClick = useCallback(() => {
    console.log('clicked');
  }, []);

  return <ChildButton onClick={handleClick} />;  // ✅ onClick 引用稳定
};

const ChildButton = React.memo(({ onClick }) => (
  <button onClick={onClick}>Click</button>
));

// 2. 作为 useEffect 的依赖
useEffect(() => {
  fetchData(userId);
}, [fetchData, userId]);  // ✅ fetchData 使用 useCallback

// 3. 传递给多个子组件，避免重复创建
const handleSubmit = useCallback(async (data) => {
  await api.submit(data);
}, []);

<Form onSubmit={handleSubmit} />
<Button onClick={handleSubmit} />
```

**useMemo 使用场景**：

```javascript
// 1. 昂贵的计算
const sortedList = useMemo(() => {
  console.log('sorting...');
  return items.sort((a, b) => a.value - b.value);
}, [items]);  // ✅ items 不变时不重新排序

// 2. 稳定的对象/数组引用
const config = useMemo(() => ({
  theme: 'dark',
  language: 'en',
}), []);  // ✅ config 引用永不变

// 3. 避免触发子组件的 useEffect
const Parent = () => {
  const config = useMemo(() => ({ api: '/api' }), []);
  return <Child config={config} />;  // ✅ config 稳定，Child 的 useEffect 不会重复执行
};

const Child = ({ config }) => {
  useEffect(() => {
    fetchData(config.api);
  }, [config]);  // config 稳定，只执行一次
};
```

**不要滥用**：

```javascript
// ❌ 简单计算不需要 useMemo
const doubled = useMemo(() => count * 2, [count]);  // 比较成本 > 计算成本

// ✅ 直接计算
const doubled = count * 2;

// ❌ 每次都创建新依赖，useMemo 无意义
const result = useMemo(() => compute(value), [{ value }]);  // 每次都是新对象

// ✅ 依赖原始值
const result = useMemo(() => compute(value), [value]);
```

```javascript
  return <div>...</div>;

// 使用 React Profiler 组件
<Profiler id="HeavyComponent" onRender={onRenderCallback}>
  <HeavyComponent />
</Profiler>

function onRenderCallback(
  id,                  // "HeavyComponent"
  phase,               // "mount" 或 "update"
  actualDuration,      // 渲染花费的时间
  baseDuration,        // 不使用 memoization 的预估时间
  startTime,           // 开始渲染的时间
  commitTime,          // 提交渲染的时间
  interactions         // 此次更新的 interactions 集合
) {
  console.log(`${id} ${phase} took ${actualDuration}ms`);
}
```

## 总结

1. **减少不必要的渲染**：React.memo、PureComponent、shouldComponentUpdate
2. **缓存函数和值**：useCallback、useMemo
3. **列表优化**：正确的 key、虚拟列表、分页
4. **代码分割**：React.lazy、路由懒加载
5. **状态管理**：状态下沉、拆分、useReducer
6. **性能分析**：React DevTools Profiler、Chrome DevTools
